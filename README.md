# BunkerGame

| 항목 | 내용 |

### 한 줄 소개

> 대기가 오염된 세계에서, 지하 벙커의 각 방을 운영하고 생존자를 파견해 자원을 모아 쉘터를 유지·확장하는 생존 관리 게임

---

## 2. 게임 컨셉

대기가 유독 가스로 오염되어 지상에서는 방독 장비 없이 생존할 수 없는 세계.

플레이어는 지하 벙커의 관리자가 되어, 소수의 생존자를 이끌고 살아남아야 한다.

벙커는 여러 개의 방으로 이루어져 있으며, 각 방은 전력·산소·식량 등 생존에 필요한 자원을 생산한다. 생존자를 방에 배치하면 해당 방이 가동되어 자원이 생산된다.

벙커 내부의 자원은 시간이 지나면 고갈되므로, 플레이어는 생존자를 지상으로 파견하여 부족한 자원을 확보해야 한다. 단, 지상은 유독 가스로 가득 차 있어 산소가 떨어지기 전에 돌아와야 한다.

확보한 자원으로 새로운 방을 제작하여 쉘터를 확장하고, 최대한 오래 생존하는 것이 목표다.

### 핵심 키워드

- 방 단위로 벙커 운영
- 생존자를 방에 배치해 자원 생산
- 지상으로 파견하여 자원 확보 (위험 감수)
- 자원으로 새로운 방 제작 및 쉘터 확장
- 자원 균형을 유지하며 생존

---

## 3. 게임 목표

플레이어의 목표는 다음과 같다.

1. 각 방에 생존자를 배치하여 전력·산소·식량을 생산한다.
2. 벙커 내부의 자원 수치를 파악하고 균형을 유지한다.
3. 자원이 부족해지면 생존자를 지상으로 파견한다.
4. 산소가 떨어지기 전에 자원을 회수하여 복귀시킨다.
5. 확보한 자원으로 새로운 방을 제작해 쉘터를 확장한다.
6. 자원 고갈이나 위기 상황을 극복하며 최대한 오래 생존한다.

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```
방에 생존자 배치
  ↓
자원 생산 (전력 / 산소 / 식량)
  ↓
자원 소비 / 시간 경과
  ↓
자원 부족 발생
  ↓
생존자 지상 파견
  ↓
자원 확보 (위험도)
  ↓
복귀 및 자원 회수
  ↓
새로운 방 제작 / 쉘터 확장
  ↓
(반복)
```

플레이어는 게임이 종료될 때까지 **배치 → 생산 → 파견 → 확장**의 과정을 반복하며 생존을 이어간다.

## 6. 핵심 시스템

### 6.1 방(Room) 시스템

벙커는 4~5개의 방으로 구성되며, 각 방은 고유한 기능을 가진다.

| 방 | 기능 | 생산 자원 |
| --- | --- | --- |
| 발전실 | 전력 생산 | 전력 |
| 정수·환기실 | 벙커 내부 공기 정화 | 산소 |
| 온실 | 식량 재배 | 식량 |
| 침실 | 생존자 체력·피로 회복 | 회복 |
| 제작실 | 새로운 방·장비 제작 | 제작 |

- 방에 생존자를 배치하면 해당 방이 가동되어 자원을 생산한다.
- 배치된 인원 수에 따라 생산 효율이 달라진다.
- 방을 가동하지 않으면 해당 자원이 점차 고갈된다.
  
### 6.2 파견(Expedition) 시스템

- 생존자를 지상으로 내보내 부족한 자원을 확보한다.
- 지상은 유독 가스 지역이므로 산소 게이지가 작동한다.
- 산소가 떨어지기 전에 복귀하지 못하면 생존자가 위험해진다.

### 6.3 제작(Craft) 시스템

- 파견으로 확보한 자원을 사용해 새로운 방을 제작한다.
- 쉘터가 확장되면 관리할 요소가 늘어나며 난이도가 상승한다.
